# Aula de JavaScript

Projeto criado durante minhas aulas de JavaScript para praticar os primeiros conceitos da linguagem. A página mostra uma mensagem de apresentação na tela e outros resultados no Console do navegador.

## O que aprendi

- Guardar informações em variáveis usando `let`
- Mostrar resultados no Console com `console.log()`
- Tomar decisões no código com `if`, `else if` e `else`
- Mudar o texto da página usando JavaScript

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Como ver o resultado

1. Baixe os arquivos deste repositório.
2. Abra o arquivo `index.html` no navegador.
3. Aperte F12 e clique na aba **Console** para ver os resultados.
